# RocWes 用户手册

面向画面组态与运维人员的使用指南：如何编辑设备画面、接入数据源、进入运行态。开发者视角请见 [开发指南](../开发指南/开发指南.md)，各协议点位格式等细节见 [数据源手册](../数据源手册/README.md)。

## 1. 产品概览

RocWes 是面向仓储自动化（WCS）场景的 SCADA 组态平台（纯桌面应用，基于 Tauri），覆盖三个环节：

1. **仿真演示**：无需真实设备，用内置模拟数据完成画面编排与联动验证；
2. **实时监控**：接入真实数据源，节点随数据实时刷新，支持边沿触发告警；
3. **运行执行**：一键进入全屏 SCADA 运行态，用于现场看板或演示汇报。

### 运行环境

RocWes 以桌面应用形式提供（安装版 NSIS 或 `npx tauri dev` 开发模式），内置 Rust 原生设备网关：

- WebSocket / HTTP / SSE / MQTT 四类 Web 协议由应用内 WebView 直连外部服务；
- 工业协议（Modbus 已支持，S7 / OPC UA 规划中）由内置网关原生 TCP 直连设备，无需任何中间件；
- 全部 7 类协议均支持演示模式，无真实设备也能完成画面开发。

> WebView 无法直接连接 PLC 等 TCP 设备，这正是内置 Rust 网关存在的核心原因。

## 2. 画面编辑

### 组件库拖拽

左侧组件库分组提供 WCS 设备（堆垛机、输送线、AGV、穿梭车、分拣机、提升机、机械臂、货架）、IoT 监控（仪表盘、折线图、指示灯）与基础图形（矩形、圆形、自定义卡片）。按住组件拖入画布即完成放置，每个设备节点自带预置数据绑定点位。

### 属性与数据绑定

点击画布节点，右侧属性面板可编辑名称、坐标等属性；「数据绑定」标签页中选择数据源实例、填写点 ID、可选编写 transform 函数把原始值映射为业务状态（如数值档位 → 中文状态）。

### 路线编辑

AGV 等移动设备支持路线编辑（路线编辑器 + 浮动窗口），定义运行路径并联动动画展示。

### 显示模式

画布支持显示模式切换（如仅图标模式），用于大图概览或低性能环境。

### 工程管理

工具栏提供保存、导出、导入与运行入口。画面以 JSON 形式保存在应用配置目录（自动持久化，重启应用不丢失），可通过导出 / 导入在机器之间迁移工程。

## 3. 节点操作手册

组件库共提供 14 类节点，分三组：基础图形（矩形 / 圆形 / 卡片节点）、WCS 设备（8 种仓储设备）、IoT 监控（仪表盘 / 折线图 / 指示灯）。

### 通用操作

| 操作 | 方式 |
| --- | --- |
| 创建节点 | 从左侧组件库按住拖入画布；设备 / IoT 节点自动生成唯一点 ID（如 `device.stacker-1`）并预置数据绑定与 transform |
| 选中 / 移动 / 缩放 | 单击选中，拖拽移动，拖拽选中框手柄缩放 |
| 查看节点详情 | 双击节点，弹出详情弹窗（基本信息：节点 ID/名称/类型/标签；运行数据：按点 ID 分组显示） |
| 删除 / 复制 / 撤销 | `Delete` 删除；`Ctrl+C` / `Ctrl+V` 复制粘贴；`Ctrl+Z` 撤销；`Ctrl+S` 保存 |
| 切换显示模式 | 工具栏切换（如仅图标模式），适合大图概览 |

> **未绑定数据源的节点保持静态值不变**：拖入节点后只是预置了点位信息，只有在属性面板「数据绑定」中选择了数据源实例才会实时刷新；需要模拟数据请先创建演示模式数据源再绑定。

### 基础节点（无数据绑定）

| 节点 | 尺寸 | 说明 |
| --- | --- | --- |
| 矩形 | 120×60 | 基础图形，上下带两个连接桩，可从连接桩拖出连线连接其他节点；双击可改文字 |
| 圆形 | 120×60 | 基础图形，用于分区标注或装饰 |
| 卡片节点 | 160×80 | 自定义信息卡片，显示标题、图标与状态文字（默认「正常」）；预置点 ID `device.card`，绑定后可用 transform 映射状态 |

### WCS 设备节点

8 种设备节点均以颜色 / 动画呈现运行状态（待机 / 运行 / 告警 / 故障），预置点 ID 前缀 `device.*`，默认 transform 把 0–100 数值映射为设备状态；接入真实设备时可在属性面板改写 transform 适配实际点位语义。

| 节点 | 尺寸 | 画面呈现 | 预置点 ID | 默认数值 → 状态映射 |
| --- | --- | --- | --- | --- |
| 堆垛机 🏗️ | 200×130 | 名称、巷道号、库位（如 05-12-03）、状态与作业进度条 | `device.stacker` | <20 待机；20–60 运行（进度随数值增加）；60–80 告警；≥80 故障 |
| 输送机 ⚡ | 220×80 | 名称、方向标识与传送带动画 | `device.conveyor` | <30 停止；30–70 运行（带动画）；≥70 故障 |
| AGV 🤖 | 160×120 | 名称、电量百分比、移动动画；支持路线联动 | `device.agv` | <20 充电中；20–40 待机；40–80 运行（电量随数值）；≥80 故障 |
| 穿梭车 🚗 | 200×100 | 名称、巷道内位置与状态 | `device.shuttle` | 位置 = 数值 mod 100；<30 待机；30–80 运行；≥80 故障 |
| 分拣机 📦 | 240×160 | 名称、分拣速度、A–D 四个格口计数与高亮 | `device.sorter` | 速度 = 30 + 数值×0.7；格口计数按数值比例累加；>90 故障 |
| 提升机 🔼 | 120×160 | 名称、当前层数（共 6 层）与升降位置 | `device.elevator` | 层数按数值百分比折算；<30 待机；30–80 运行；≥80 故障 |
| 机械手 🦾 | 150×130 | 名称、关节角度动画、夹爪开合 | `device.robot` | 分档：待机（0°/30°）→ 运行夹取（60°/90° 夹爪张开）→ ≥80 故障 |
| 货架 🏛️ | 240×150 | 三维货架模型，默认 1 排×6 列×4 层，逐格显示空 / 占用 / 预留 | `device.rack` | 预置 transform 随机刷新全部货位状态；库位编号规则「排_列_层」 |

**AGV 路线联动**：在底部「路线」面板（或路线浮动窗口）新建路线并绘制航点后，AGV 可绑定路线展示运行动画；航点右键可插入 / 删除 / 设为站点。

### IoT 监控节点

| 节点 | 尺寸 | 画面呈现 | 预置点 ID | 可配置项 |
| --- | --- | --- | --- | --- |
| 仪表盘 📊 | 200×180 | 指针表盘 + 当前值；默认量程 0–100、初值 50 | `sensor.temp` | 标题、单位、最小 / 最大值；默认 transform 保留一位小数 |
| 折线图 📈 | 260×160 | 最近 20 个采样点的实时曲线 | `sensor.chart` | 标题；默认 transform 保留一位小数 |
| 指示灯 💡 | 130×70 | 标签 + 灯色（off / warning / on / error 四种） | `device.status` | 默认映射：>80 亮灯；50–80 告警；20–50 熄灭；≤20 故障 |

## 4. 数据源管理

打开数据源对话框，统一管理 7 种协议的数据源：WebSocket、HTTP 轮询、SSE、MQTT、西门子 S7、OPC UA、Modbus。

### 演示模式 vs 真实模式

每个数据源可一键切换演示 / 真实模式：

- **演示模式**：不连真实设备，由内置演示引擎（Rust DemoAdapter）生成特征模拟曲线（正弦、阶梯、三角波等），并自动注入该协议的特征样例点位。全部 7 类协议均可演示，无需任何外部服务。
- **真实模式**：填写设备连接参数。桌面版工业协议直接连设备，无需任何中间网关进程。

### 设备参数速查

| 协议 | 真实模式参数 | 支持状态 |
| --- | --- | --- |
| WebSocket / HTTP / SSE / MQTT | 服务地址（及主题） | ✅ WebView 直连外部服务 |
| Modbus | 主机、端口（默认 502）、从站地址 | ✅ 桌面原生直连 |
| 西门子 S7 | 主机、机架、槽号（默认 2） | ⏳ 桌面适配器开发中，敬请期待；当前可用演示模式 |
| OPC UA | 端点 URL（`opc.tcp://...`） | ⏳ 桌面适配器开发中，敬请期待；当前可用演示模式 |

### 网关监控面板

数据源对话框内置监控面板，实时显示：连通性状态、设备连接消息、建连耗时、已订阅点位的实时值与数据质量、错误告警。配置数据源后可先在监控面板验证连通与点位，再上画布绑定。

## 5. 运行态

点击工具栏「运行」进入 SCADA 运行态（`/run` 路由）：全屏展示画面、隐藏全部编辑工具，数据服务持续订阅、节点实时刷新。适合现场看板大屏或汇报演示；返回编辑器即可继续修改。

## 6. 常见问题

**Q：为什么工业协议（PLC）不能像 WebSocket 那样直接连？**
WebView 出于安全限制无法建立原生 TCP 连接。RocWes 内置 Rust 原生网关代连设备，在数据源对话框填设备参数即可，无需额外网关进程。

**Q：S7 / OPC UA 数据源真实模式提示「适配器待实现」？**
桌面网关目前已支持 Modbus；S7 与 OPC UA 适配器在路线图上（见 [文档中心](../README.md) 规划），当前可先用演示模式完成画面开发。

**Q：演示模式的数据是真的吗？**
不是。演示模式由系统生成模拟曲线，仅用于画面开发与验证；接入真实设备请切换真实模式。

**Q：内置演示标识地址（ws://localhost:8080 等）为什么连不上？**
这些地址只是演示模式的识别标识与表单预填值，背后没有对应的本地服务；需要模拟数据请直接使用数据源的「演示模式」开关（由内置 Rust 演示引擎生成数据）。

**Q：工程文件存在哪里？**
保存在应用配置目录的 JSON 文件中（Windows 为 `%APPDATA%\com.rocwes.desktop\`，包含画面 `editor.json`、数据源 `datasources.json`、路线 `routes.json`、主题 `theme.json`），自动持久化。需要换机器或备份时，用「导出」保存工程文件，再在目标环境「导入」。
