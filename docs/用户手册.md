# RocWes 用户手册

面向画面组态与运维人员的使用指南：如何编辑设备画面、接入数据源、进入运行态。开发者视角请见 [开发指南](./开发指南.md)，各协议点位格式等细节见 [数据源手册](./数据源手册/README.md)。

## 1. 产品概览

RocWes 是面向仓储自动化（WCS）场景的 SCADA 组态平台，覆盖三个环节：

1. **仿真演示**：无需真实设备，用内置模拟数据完成画面编排与联动验证；
2. **实时监控**：接入真实数据源，节点随数据实时刷新，支持边沿触发告警；
3. **运行执行**：一键进入全屏 SCADA 运行态，用于现场看板或演示汇报。

### 两种运行形态

| 形态 | 启动方式 | 特点 |
| --- | --- | --- |
| 桌面版（推荐） | 安装 RocWes 桌面应用 | 内置原生设备网关，工业协议（Modbus 已支持，S7 / OPC UA 规划中）开箱直连，全部协议支持演示模式 |
| 浏览器版 | 浏览器访问部署地址 | 无需安装；可直连 WebSocket / HTTP / SSE / MQTT 四类协议；工业协议请使用桌面版 |

> 浏览器无法直接连接 PLC 等 TCP 设备，这是桌面版存在的核心原因。

## 2. 画面编辑

### 组件库拖拽

左侧组件库分组提供 WCS 设备（堆垛机、输送线、AGV、穿梭车、分拣机、提升机、机械臂、货架）、IoT 监控（仪表盘、折线图、指示灯）与基础图形（矩形、圆形、自定义卡片）。按住组件拖入画布即完成放置，每个设备节点自带预置数据绑定点位。

### 属性与数据绑定

点击画布节点，右侧属性面板可编辑名称、坐标等属性；「数据绑定」标签页中选择数据源实例、填写点 ID、可选编写 transform 函数把原始值映射为业务状态（如数值档位 → 中文状态）。

### 路线编辑

AGV 等移动设备支持路线编辑（路线编辑器 + 浮动窗口），定义运行路径并联动动画展示。

### 显示模式

画布支持显示模式切换（如仅图标模式），用于大图概览或低性能环境。

### 工程管理

工具栏提供保存、导出、导入与运行入口。画面以 JSON 形式保存在浏览器本地（自动持久化），可通过导出 / 导入在机器间迁移工程。

## 3. 数据源管理

打开数据源对话框，统一管理 7 种协议的数据源：WebSocket、HTTP 轮询、SSE、MQTT、西门子 S7、OPC UA、Modbus。

### 演示模式 vs 真实模式

每个数据源可一键切换演示 / 真实模式：

- **演示模式**：不连真实设备，由系统生成特征模拟曲线（正弦、阶梯、三角波等），并自动注入该协议的特征样例点位。桌面版全部 7 类协议均可演示；浏览器开发环境（`npm run dev`）下 ws/http/sse/mqtt 由内置服务提供。
- **真实模式**：填写设备连接参数。桌面版工业协议直接连设备，无需任何中间网关进程。

### 设备参数速查

| 协议 | 真实模式参数 | 桌面版状态 |
| --- | --- | --- |
| WebSocket / HTTP / SSE / MQTT | 服务地址（及主题） | ✅ 浏览器也可用 |
| Modbus | 主机、端口（默认 502）、从站地址 | ✅ 桌面原生直连 |
| 西门子 S7 | 主机、机架、槽号（默认 2） | ⏳ 桌面适配器开发中，敬请期待；当前可用演示模式 |
| OPC UA | 端点 URL（`opc.tcp://...`） | ⏳ 桌面适配器开发中，敬请期待；当前可用演示模式 |

### 网关监控面板

数据源对话框内置监控面板，实时显示：连通性状态、设备连接消息、建连耗时、已订阅点位的实时值与数据质量、错误告警。配置数据源后可先在监控面板验证连通与点位，再上画布绑定。

## 4. 运行态

点击工具栏「运行」进入 SCADA 运行态（`/run` 路由）：全屏展示画面、隐藏全部编辑工具，数据服务持续订阅、节点实时刷新。适合现场看板大屏或汇报演示；返回编辑器即可继续修改。

## 5. 常见问题

**Q：浏览器版为什么连不上 PLC？**
浏览器出于安全限制无法建立原生 TCP 连接。请使用桌面版（内置 Rust 原生网关直连设备）。

**Q：S7 / OPC UA 数据源真实模式提示「适配器待实现」？**
桌面网关目前已支持 Modbus；S7 与 OPC UA 适配器在路线图上（见 [文档中心](./README.md) 规划），当前可先用演示模式完成画面开发。

**Q：演示模式的数据是真的吗？**
不是。演示模式由系统生成模拟曲线，仅用于画面开发与验证；接入真实设备请切换真实模式。

**Q：生产环境里演示地址（localhost:8080 等）为什么连不上？**
内置模拟服务只在开发环境提供。生产环境请配置外部真实服务地址，或使用桌面版演示模式。

**Q：工程文件存在哪里？**
保存在浏览器本地存储（自动持久化）。换机器或清缓存前请先用「导出」备份，再在目标环境「导入」。
