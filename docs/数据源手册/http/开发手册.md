# HTTP 轮询 数据源 · 开发手册

> 面向维护、调试或扩展 HTTP 轮询数据接入的开发者。数据源类型标识：`http`。

## 一、架构与数据流

HTTP 轮询基于浏览器原生 `fetch`，**无网关**，每个数据点独立一个定时器周期性 GET：

```
┌────────────┐  subscribe(pointId)  ┌────────────────────┐  GET url?pointId=x  ┌──────────┐
│ X6 节点     │ ───────────────────▶ │ HttpPollingService │ ──────────────────▶ │ REST 接口 │
│ node.data   │                      │  每点一个 setInterval│ ◀────────────────── │          │
│  .value     │ ◀─────────────────── │                    │   {id,value,...}     └──────────┘
└────────────┘   DataPoint 回调       └────────────────────┘   （默认 2000ms/次）
```

## 二、核心类型定义

复用统一的 `DataPoint` / `IDataService` / `DataBindingConfig`（见 `src/services/DataService.ts`，与 WebSocket 一致）。其中 `DataBindingConfig.interval` 字段即为 HTTP 轮询间隔预留（毫秒）。

数据源实例 `DataSource.type = 'http'`，`config` 通常为空。

## 三、前端 Service 实现

文件：`src/services/HttpPollingService.ts`。

```ts
constructor(url: string, interval = 2000) {
    this.url = url
    this.interval = interval
}

subscribe(pointId: string, callback: DataCallback): void {
    if (!this.callbacks.has(pointId)) this.callbacks.set(pointId, [])
    this.callbacks.get(pointId)!.push(callback)

    if (!this.timers.has(pointId)) {
        const poll = async () => {
            try {
                const sep = this.url.includes('?') ? '&' : '?'
                const resp = await fetch(`${this.url}${sep}pointId=${encodeURIComponent(pointId)}`)
                if (!resp.ok) throw new Error(`HTTP ${resp.status}`)
                const data = await resp.json()
                const point: DataPoint = {
                    id: data.id || pointId,
                    value: data.value ?? data.data,
                    timestamp: data.timestamp || Date.now(),
                    quality: data.quality || 'good',
                }
                for (const cb of this.callbacks.get(pointId) || []) cb(point)
            } catch (e) {
                console.warn('[HTTP] 轮询失败:', e)
            }
        }
        poll()                                            // 立即拉取一次
        const timer = window.setInterval(poll, this.interval)
        this.timers.set(pointId, timer)
    }
}
```

要点：

- **每点独立定时器**：`timers: Map<pointId, number>`，订阅时若该点尚无定时器则创建；`unsubscribe` 清除对应定时器。
- **立即首拉**：订阅后先同步 `poll()` 一次，避免首个间隔内无数据。
- **URL 拼接**：自动判断用 `?` 还是 `&` 追加 `pointId`，并对 pointId 做 `encodeURIComponent`。
- **错误隔离**：单次请求失败仅 `console.warn`，不中断后续轮询。
- `isConnected()` 恒为 `true`（无连接概念）；`disconnect()` 清除全部定时器与回调。

> 注意：`useDataService` 中创建时为 `new HttpPollingService(sourceUrl)`，使用默认 2000ms。如需按数据源自定义间隔，可扩展为读取 `sourceConfig.interval` 传入构造函数。

## 四、数据格式与点ID约定

| 方向 | 内容 | 说明 |
| --- | --- | --- |
| 前端 → 接口 | `GET <url>?pointId=<pointId>` | 轮询请求 |
| 接口 → 前端 | `{ "id"?, "value", "timestamp"?, "quality"? }` | JSON 响应 |

点ID通过查询参数传递，无格式约束。

## 五、内置模拟服务

文件：`mock/server.ts` 的 `startHttpServer()`，监听 `http://localhost:8081`，路径 `/api/data`，默认开启 CORS：

```ts
const server = http.createServer((req, res) => {
    const url = new URL(req.url || '/', `http://localhost:${MOCK_PORTS.http}`)
    res.setHeader('Access-Control-Allow-Origin', '*')
    res.setHeader('Access-Control-Allow-Methods', 'GET, OPTIONS')
    res.setHeader('Access-Control-Allow-Headers', '*')
    if (req.method === 'OPTIONS') { res.writeHead(204); res.end(); return }
    if (url.pathname === '/api/data') {
        const pointId = url.searchParams.get('pointId') || 'default'
        res.writeHead(200, { 'Content-Type': 'application/json' })
        res.end(JSON.stringify({ id: pointId, value: httpValue(pointId), timestamp: Date.now(), quality: 'good' }))
        return
    }
    res.writeHead(404, { 'Content-Type': 'text/plain' }); res.end('Not Found')
})
```

数据生成算法（`mock/generators.ts`）——随机游走，0~100 缓慢漂移，每个 pointId 维护独立状态：

```ts
const httpState = new Map<string, number>()
export function httpValue(pointId: string): number {
  const prev = httpState.get(pointId) ?? 50
  let next = prev + (Math.random() - 0.5) * 12
  next = Math.max(0, Math.min(100, next))
  httpState.set(pointId, next)
  return round1(next)
}
```

## 六、路由与节点绑定机制

`useDataService.ts`：


## 七、扩展指南

- **自定义轮询间隔**：在 `useDataService` 改为 `new HttpPollingService(sourceUrl, sourceConfig?.interval ?? 2000)`，并在数据源 `config` 中暴露 `interval` 字段、在 `DataSourceDialog` 增加对应输入项。
- **改为 POST 或带鉴权**：在 `poll()` 中替换 `fetch` 选项（`method`、`headers`），例如加入 `Authorization`。
- **批量拉取**：当前是每点一次请求；若接口支持批量，可重构为单定时器拉取多点再分发到各回调。
- **修改模拟数据**：编辑 `httpValue()`（如改为有界正弦、阶梯）。

## 八、调试与验证

1. `npm run dev`，控制台出现 `[mock] HTTP 轮询服务已启动: http://localhost:8081/api/data?pointId=xxx`。
2. 浏览器直接访问 `http://localhost:8081/api/data?pointId=env.humidity.01` 应返回 JSON。
3. 浏览器控制台动态验证：

```js
const { HttpPollingService } = await import('http://localhost:5173/src/services/HttpPollingService.ts')
const svc = new HttpPollingService('http://localhost:8081/api/data', 1000)
svc.subscribe('env.humidity.01', p => console.log(p.value))
// 每秒输出随机游走数值；验证完 svc.disconnect()
```

4. `curl` 验证接口：`curl "http://localhost:8081/api/data?pointId=x"`。
