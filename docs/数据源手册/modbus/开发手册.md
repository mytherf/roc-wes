# Modbus 数据源 · 开发手册

> 面向维护、调试或扩展 Modbus 数据接入的开发者。数据源类型标识：`modbus`。

## 一、架构与数据流

Modbus TCP 为原生 TCP 二进制协议，浏览器无法直连，需经独立 WS 网关桥接（modbus-serial）。两条链路订阅协议一致：

```
演示模式：
  X6 节点 ── ModbusService ──WS──▶ 内置演示网关 mock/server.ts (8086 /modbus) ──▶ modbusValue() 模拟数据

真实模式：
  X6 节点 ── ModbusService ──WS──▶ 独立网关 gateway/modbus-gateway.ts (19100 /modbus)
                                          │ modbus-serial (Modbus TCP)
                                          ▼
                              真实从站 / 仿真从站 gateway/simulator.ts (19502)
```

前端 → 网关：`{action:'configure',config}` / `{action:'subscribe',topic}` / `{action:'unsubscribe',topic}`；网关 → 前端：`{type:'status',connected,message}` 与 `{topic,value,timestamp,quality}`。

## 二、核心类型定义

`src/services/ModbusService.ts` 定义设备配置：

```ts
export interface ModbusDeviceConfig {
    host?: string          // 设备主机地址
    port?: number          // Modbus TCP 端口（默认 502）
    unitId?: number        // 从站地址（默认 1）
    pollInterval?: number  // 轮询间隔毫秒（默认 1000）
    demo?: boolean         // true=内置演示网关，false=独立真实网关
}
```

复用统一 `DataPoint` / `IDataService` / `DataBindingConfig`。数据源实例 `DataSource.type='modbus'`，`config` 即上述参数。

## 三、前端 Service 实现

`src/services/ModbusService.ts`：`ModbusService(url, config={})`，结构与 S7/Opc Service 一致——onopen 先 `sendConfigure()` 再重订阅，处理网关 `status` 帧，3s 自动重连。`sendConfigure()` 发送 `{ action:'configure', config: this.config }`。数据帧按 `topic||id||pointId` 匹配，数值取 `value??data`。

## 四、数据格式与点ID约定

点ID格式 `<type>:<addr>`，type ∈ `holding`/`input`/`coil`/`discrete`，addr 为十进制地址。网关据此选择功能码（见下）。

## 五、内置演示网关

`mock/server.ts` 的 `startModbusServer()`，监听 `ws://localhost:8086/modbus`，与 WS 服务相同订阅协议，每秒推送 `modbusValue()`（忽略设备配置）：

```ts
const wss = new WebSocketServer({ port: MOCK_PORTS.modbus, path: '/modbus' })
// 维护 clientPoints，每秒推送：
ws.send(JSON.stringify({ topic: pointId, value: modbusValue(pointId, t), timestamp: t, quality: 'good' }))
```

数据算法（`mock/generators.ts`）——三角波，12s 周期 10~90 线性往返：

```ts
export function modbusValue(pointId: string, t: number): number {
  const period = 12000
  const offset = (hashPhase(pointId) / (2 * Math.PI)) * period
  const p = ((t + offset) % period) / period
  const tri = p < 0.5 ? p * 2 : 2 - p * 2
  return round1(10 + tri * 80)
}
```

## 六、独立真实网关

`gateway/modbus-gateway.ts`，`WebSocketServer({ port: 19100, path: '/modbus' })`（`GATEWAY_PORT` 可覆盖）。收到 configure 后用 **modbus-serial** 连接：

```ts
import ModbusSerial from 'modbus-serial'
const client = new ModbusSerial()
client.setTimeout(3000)
await client.connectTCP(s.config.host, { port: s.config.port })
client.setID(s.config.unitId)
```

逐点读取（按点ID前缀选择功能码）：

```ts
const [type, addrStr] = pointId.split(':')
const addr = parseInt(addrStr, 10)
switch (type) {
  case 'holding':  return (await client.readHoldingRegisters(addr, 1)).data[0]   // FC03
  case 'input':    return (await client.readInputRegisters(addr, 1)).data[0]     // FC04
  case 'coil':     return (await client.readCoils(addr, 1)).data[0] ? 1 : 0      // FC01
  case 'discrete': return (await client.readDiscreteInputs(addr, 1)).data[0] ? 1 : 0  // FC02
  default: throw new Error(`不支持的点类型: ${type}`)
}
```

轮询回推（间隔 `Math.max(200, pollInterval||1000)`）：成功发 `{topic,value,timestamp,quality:'good'}`，失败发 `{topic,value:null,timestamp,quality:'bad',error}`。config 默认 `host 127.0.0.1 / port 502 / unitId 1 / pollInterval 1000`。关闭：`await client.close(() => {})`。

## 七、仿真从站

`gateway/simulator.ts`，基于 modbus-serial 内置 `ServerTCP`，监听 19502（`SIM_PORT`），`unitID: 255` 响应所有从站地址：

```ts
function triangle(addr: number, t: number): number {
  const period = 12000
  const p = ((t + phase(addr) * 1000) % period) / period
  const tri = p < 0.5 ? p * 2 : 2 - p * 2
  return Math.round(100 + tri * 800)        // 100~900
}
const vector = {
  getInputRegister(addr) { return triangle(addr, Date.now()) },
  getHoldingRegister(addr) { return triangle(addr, Date.now()) },
  getCoil(addr) { return Math.floor(Date.now() / 3000 + addr) % 2 },        // 每 3s 翻转
  getDiscreteInput(addr) { return Math.floor(Date.now() / 3000 + addr) % 2 },
  setRegister(addr, value) { console.log(`写保持寄存器 ${addr} = ${value}`) },
  setCoil(addr, state) { console.log(`写线圈 ${addr} = ${state}`) },
}
new ModbusSerial.ServerTCP(vector, { host: HOST, port: PORT, unitID: 255, debug: false })
```

## 八、路由与节点绑定机制

`useDataService.ts`：

```ts
case 'modbus':
    service = new ModbusService(sourceUrl, sourceConfig)
    break
```

缓存键含 `JSON.stringify(config)`。节点 `binding.sourceId` → store 解析 `ds.type/url/config`。

## 九、扩展指南

- **多寄存器合并（浮点/32 位）**：当前每点读 1 个寄存器。可在点ID引入长度/类型（如 `holding:0:float`），用 `readHoldingRegisters(addr, 2)` 读 2 寄存器后按大/小端组合成 float。
- **写操作**：网关增加 `{action:'write',topic,value}`，调用 `writeRegister`/`writeCoil`，并在 Service/绑定层暴露下发接口。
- **批量读取**：连续地址可用 `readHoldingRegisters(addr, count)` 一次读取再分发，降低通信次数。
- **修改仿真数据**：编辑 `simulator.ts` 的 `triangle()`/vector；演示网关数据改 `generators.ts` 的 `modbusValue()`。

## 十、调试与验证

1. 启动仿真链路：

```bash
npm run simulator   # 19502 仿真从站
npm run gateway     # 19100 网关
```

2. 浏览器控制台动态验证：

```js
const { ModbusService } = await import('http://localhost:5173/src/services/ModbusService.ts')
const svc = new ModbusService('ws://localhost:19100/modbus', { host:'127.0.0.1', port:19502, unitId:1, pollInterval:300, demo:false })
svc.subscribe('holding:100', p => console.log(p.value, p.quality))
// 输出 100~900 三角波，quality good；验证完 svc.disconnect()
```

3. 环境变量：`GATEWAY_PORT`（网关）、`SIM_PORT`/`SIM_HOST`（仿真）。
