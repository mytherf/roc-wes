# Modbus 数据源 · 用户使用手册

> 适用版本：roc-wes（桌面版 / 浏览器版） ｜ 数据源类型标识：`modbus` ｜ 桌面版真实模式：✅ 已支持（Rust 原生网关直连）

## 一、简介

Modbus 是工业领域历史最悠久、应用最广泛的开放协议之一，几乎所有品牌的 PLC、仪表、变频器、传感器都支持它。Modbus TCP 在以太网上以寄存器为单位读写数据，模型简单清晰：四类数据区（线圈、离散输入、输入寄存器、保持寄存器），按地址访问。

Modbus TCP 是基于 TCP 的二进制协议，**浏览器无法直接连接**。在 roc-wes 桌面版中，内置的 Rust 原生网关直接连接 Modbus 从站设备（无需任何中间网关进程与本地端口）；无需真实硬件时，可切换演示模式由系统生成模拟数据。

## 二、适用场景

- 现场设备支持 Modbus TCP（大量 PLC、智能仪表、电力监测仪、温湿度变送器等）。
- 需要按寄存器地址精确读写，且设备数据模型简单（数值/开关量）。
- 多品牌设备统一接入（Modbus 是事实标准）。

西门子 PLC 优先用 [S7](../s7/用户使用手册.md)（更丰富的数据区）；需要标准化信息建模用 [OPC UA](../opc/用户使用手册.md)。

## 三、两种连接模式

| 模式 | 数据来源 | 用途 | 是否需真实设备 |
| --- | --- | --- | --- |
| 演示模式 | 桌面版内置模拟曲线（Rust DemoAdapter） | 快速体验、画面开发 | 否 |
| 真实设备 | 桌面版 Rust 网关直连从站（tokio-modbus） | 连接真实 Modbus 从站 | 是 |

两种模式点位格式一致，区别仅在数据源「连接模式」与真实模式需填设备参数。

> 浏览器版无法连接 Modbus 设备（浏览器无原生 TCP），请使用桌面版。

## 四、快速开始（演示模式，3 步上手）

**第 1 步：创建数据源**

「🔌 数据源管理」→「＋ 新增数据源」：

- 名称：`内置Modbus模拟源`
- 类型：`Modbus`
- 连接模式：演示模式

**第 2 步：绑定节点**

选中节点 → 「数据绑定」标签页：

- 数据源：`内置Modbus模拟源`
- 点ID：`holding:100`（演示模式下任意合法格式的地址都返回模拟值）
- 转换函数：留空

**第 3 步：观察数据**

节点显示按周期变化的模拟数值；打开数据源的网关监控面板可以看到连接状态与点位实时值。

## 五、配置项说明

真实模式下需配置：

| 字段 | 说明 | 默认值 | 示例 |
| --- | --- | --- | --- |
| 连接模式 | 演示模式 / 真实设备 | 演示 | 真实设备 |
| 主机地址 | Modbus 从站设备 IP（真实模式必填） | `127.0.0.1` | `192.168.0.30` |
| 端口 | Modbus TCP 端口 | `502` | `502` |
| 从站地址(unitId) | 从站编号（设备地址） | `1` | `1` |
| 轮询间隔(ms) | 网关读取寄存器的周期 | `1000` | `500` |

> unitId 必须与设备配置的从站地址一致，填错会读不到数据。

## 六、点ID（寄存器地址）填写规则

点ID格式为 `<数据区>:<地址>`（地址为 0 基），四类数据区对应 Modbus 四种数据类型：

| 前缀 | 数据区 | Modbus 功能码 | 取值类型 | 示例 |
| --- | --- | --- | --- | --- |
| `holding:` | 保持寄存器 | FC03 | 数值（0~65535） | `holding:100` |
| `input:` | 输入寄存器 | FC04 | 数值（只读） | `input:200` |
| `coil:` | 线圈 | FC01 | 开关量（true/false） | `coil:0` |
| `discrete:` | 离散输入 | FC02 | 开关量（只读） | `discrete:0` |

注意 Modbus 有「0 基/1 基」「带区偏移地址」等多种编址习惯，请以设备说明书的寄存器表为准（本系统按 0 基原始地址传递给设备）。

## 七、实际案例：电力监测仪三相电流监控

**场景**：一台 Modbus TCP 电力监测仪（IP `192.168.1.80`，从站地址 1），保持寄存器 0~2 分别为 A/B/C 三相电流（×0.1A），线圈 0 为报警输出。需要在画布上显示三相电流，并用指示灯显示报警状态。

**操作步骤**（桌面版）：

1. 数据源管理 → 新增：
   - 名称：`电力监测仪`
   - 类型：`Modbus`
   - 连接模式：真实设备
   - 主机地址：`192.168.1.80`，端口 `502`，从站地址 `1`
2. 在网关监控面板确认「设备已连接」，样例点位有实时值。
3. 画布放置 3 个数字标签 + 1 个指示灯，绑定该数据源，点ID分别填：
   - A 相：`holding:0`，转换函数 `(raw) => (raw * 0.1).toFixed(1)`（换算成实际电流）
   - B 相：`holding:1`，转换函数同上
   - C 相：`holding:2`，转换函数同上
   - 报警：`coil:0`，转换函数 `(raw) => raw ? '报警' : '正常'`

**预期效果**：三相电流按轮询间隔刷新并换算为实际安培值；报警指示灯随线圈 0 通断切换。

## 八、连接真实设备 / 软件仿真

**连接真实从站**：确认设备 IP 可达、Modbus TCP 端口（默认 502）开放、从站地址正确，然后在数据源真实模式填 host/port/unitId 即可——桌面版会直接建立 TCP 连接，无需启动任何网关进程。

**用软件仿真从站验证（无需硬件）**：旧版内置的 Node 仿真从站已随 Node 网关一并退役，可用任意 Modbus TCP 从站仿真工具替代（如 pymodbus、diagslide、ModRSsim2 等），启动后把数据源指向其监听地址即可按真实链路验证。

## 九、常见问题

**Q：监控面板显示连接失败 / 读不到数据？**
检查：① host/port 是否正确、设备是否上电联网；② unitId 是否与设备从站地址一致；③ 防火墙是否放行 502；④ 寄存器地址是否在设备有效范围内。连接失败时桌面网关会自动指数退避重连（2 秒起、上限 30 秒），设备恢复后无需手工操作。

**Q：读到的数值和说明书对不上（差 1 或差一个区）？**
多为 Modbus 编址习惯差异（0 基 vs 1 基、地址是否含区偏移 40001 等）。本系统按原始 0 基地址传递，请对照设备寄存器表换算（如说明书「40001」对应 `holding:0`）。

**Q：浮点数怎么读？**
当前每点读 1 个寄存器（16 位）。若设备用 2 个寄存器存浮点，需要由开发侧扩展多点合并读取（见开发手册「扩展方向」）。

## 十、注意事项

- 轮询间隔最小 200ms；从站设备通信能力有限，测点多时建议适当放宽间隔。
- 同一数据区内地址连续的点位会被自动合并为批量读取，对设备更友好（见开发手册）。
- unitId 填错会读到空/异常，务必核对设备地址。
- 生产环境注意 Modbus 缺乏内建加密，关键场景建议置于隔离工业网络或加网关安全策略。
