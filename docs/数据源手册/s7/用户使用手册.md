# 西门子 S7 数据源 · 用户使用手册

> 适用版本：roc-wes（桌面版） ｜ 数据源类型标识：`s7` ｜ 桌面版真实模式：✅ 已上线

## 一、简介

西门子 S7 数据源用于接入西门子 S7 系列 PLC（S7-300/400/1200/1500 等），通过 **S7comm 协议**读写 PLC 的数据块（DB）、标志位（M 区）、输入/输出（I/Q 区）等寄存器。这是工厂车间最常见的 PLC 接入方式之一。

S7comm 是基于 TCP 的二进制协议，**浏览器无法直接连接 PLC**。桌面版由内置 Rust 网关原生连接 PLC（无需中间网关进程）；画面开发阶段也可先用**演示模式**完成全部联动验证，随后一键切换真实模式。

## 二、现状说明（重要）

| 能力 | 状态 |
| --- | --- |
| 演示模式（桌面版） | ✅ 可用：内置模拟曲线，任意点 ID 均返回模拟值 |
| 真实模式（桌面版） | ✅ 可用：Rust 原生 S7comm 客户端（snap7-client）直连 PLC |
| 浏览器版 | ❌ 无法连接（浏览器无原生 TCP，内置 Node 网关已退役） |

推荐工作流：**演示模式开发画面 → 一键切换真实模式**（点 ID 与设备参数格式保持不变）。技术实现见 [开发手册](./开发手册.md)。

## 三、适用场景

- 西门子 S7-300/400（经典产线主力机型）。
- S7-1200/1500（需开启 PUT/GET 访问，槽号通常为 1）。
- 需要按 DB/M/I/Q 地址精确读写、数据模型以寄存器和位为主的场景。

多厂商统一接入或需要标准化信息建模时考虑 [OPC UA](../opc/用户使用手册.md)；非西门子设备优先 [Modbus](../modbus/用户使用手册.md)。

## 四、快速开始（演示模式，3 步上手）

**第 1 步：创建数据源**

「🔌 数据源管理」→「＋ 新增数据源」：

- 名称：`内置S7模拟源`
- 类型：`西门子 S7`
- 连接模式：演示模式

**第 2 步：绑定节点**

选中节点 → 「数据绑定」标签页：

- 数据源：`内置S7模拟源`
- 点ID：`DB1,REAL0`（演示模式下任意合法格式的地址都返回模拟值）
- 转换函数：留空

**第 3 步：观察数据**

节点显示按周期变化的模拟数值；网关监控面板可看到连接状态与点位实时值。

## 五、配置项说明

真实模式需配置：

| 字段 | 说明 | 默认值 | 示例 |
| --- | --- | --- | --- |
| 连接模式 | 演示模式 / 真实设备 | 演示 | 真实设备 |
| 主机地址 | PLC IP（真实模式必填） | `127.0.0.1` | `192.168.0.10` |
| 端口 | S7comm 端口 | `102` | `102` |
| 机架号(rack) | PLC 机架 | `0` | `0` |
| 槽号(slot) | PLC 槽号 | `2` | S7-300/400 常为 `2`；S7-1200/1500 常为 `1` |
| 轮询间隔(ms) | 读取周期 | `1000` | `500` |

> rack/slot 填错是 S7 连接失败最常见的原因之一：S7-300/400 默认 rack 0 / slot 2；S7-1200/1500 通常为 rack 0 / slot 1（且需在 TIA 中开启 PUT/GET）。

## 六、点ID（PLC 地址）填写规则

点 ID 采用 nodes7 风格地址字符串，**这是 S7 数据源最容易出错的地方**：

| 数据区 | 语法 | 示例 | 说明 |
| --- | --- | --- | --- |
| DB 数据块 | `DB{n},{类型}{偏移}` | `DB1,REAL0` / `DB1,INT4` / `DB1,WORD6` | 类型：REAL/LREAL/INT/WORD/DINT/DWORD/BYTE(B) |
| DB 位 | `DB{n},X{字节}.{位}` | `DB1,X0.0` | 布尔量（X 可省略：`DB1,0.0`） |
| DB 数组 | `DB{n},{类型}{偏移}.{长度}` | `DB1,REAL0.4` | ⏳ 暂不支持（v2 规划，当前会跳过该点） |
| M 区 | `MB` / `MW` / `MD{偏移}` | `MB0` / `MW0` / `MD0` | 字节/字/双字 |
| M 区位 | `M{字节}.{位}` | `M0.0` | 布尔量 |
| I / Q 区 | `IB/IW/ID{n}` / `QB/QW/QD{n}` | `IB0` / `QW2` | 输入/输出 |

⚠️ `DB1,REAL0,1`（三逗号）是非法写法；数组长度用 `.`（如 `DB1,REAL0.4`）。

## 七、实际案例：堆垛机状态监控（演示模式开发 → 真实切换）

**场景**：一台 S7-300 控制的堆垛机（IP `192.168.1.20`，rack 0 / slot 2），DB1 中 REAL0 为当前层数、REAL4 为当前列数、X8.0 为运行状态位。

**操作步骤**：

1. 数据源管理 → 新增：名称 `堆垛机1号PLC`，类型 `西门子 S7`，先用**演示模式**；
2. 画布放置堆垛机节点 + 2 个数字标签 + 1 个指示灯，绑定该数据源：
   - 层数：`DB1,REAL0`，转换函数 `(raw) => Math.round(raw)`
   - 列数：`DB1,REAL4`，转换函数同上
   - 运行：`DB1,X8.0`，转换函数 `(raw) => raw ? '运行' : '停止'`
3. 演示模式下验证画面联动与告警逻辑；
4. 切换真实模式：填主机 `192.168.1.20`、机架 `0`、槽号 `2`，监控面板确认连接后即为真实数据。

## 八、常见问题

**Q：真实模式连接失败？**
优先核对 rack/slot（S7-300/400 常为 0/2，S7-1200/1500 常为 0/1）与网络可达性；S7-1200/1500 还需在 TIA 中开启 PUT/GET 或对优化访问 DB 块关闭优化。仍失败时查看网关日志（`gateway_s7` 通道）定位。

**Q：浏览器版能连 S7 吗？**
不能。浏览器无法建立 TCP 连接，原 Node WS 网关已退役；请使用桌面版。

**Q：演示模式的点位格式和真实模式一样吗？**
一样。演示模式接受相同格式的点 ID 并返回模拟值，切换真实模式无需改绑定。

## 九、注意事项

- 轮询间隔最小 200ms；S7 PLC 通信资源（连接数/PDU）有限，测点多时建议放宽间隔。
- rack/slot、PUT/GET 设置错误是真实连接失败主因，切换真实模式前先与电气工程师核对。
- S7comm 无内建加密，关键场景建议置于隔离工业网络。
