# S7 数据源 · 用户使用手册

> 适用版本：roc-wes 编辑器（桌面版） ｜ 数据源类型标识：`s7` ｜ 演示模式：无需填写地址（数据由内置模拟引擎生成）

## 一、简介

西门子 S7 数据源用于接入西门子 S7 系列 PLC（S7-300/400/1200/1500 等），通过 **S7comm 协议**读写 PLC 的数据块（DB）、标志位（M 区）、输入/输出（I/Q 区）等寄存器。这是工厂车间最常见的 PLC 接入方式之一。

S7comm 是基于 TCP 的二进制协议，**浏览器无法直接连接 PLC**。桌面版由内置 Rust 网关原生连接 PLC（无需中间网关进程），浏览器版无法使用；画面开发阶段可先用**演示模式**完成全部联动验证，随后一键切换真实模式。

## 二、适用场景

适合以下情况优先选择西门子 S7：

- 西门子 S7-300/400（经典产线主力机型）。
- S7-1200/1500（需开启 PUT/GET 访问，槽号通常为 1）。
- 需要按 DB/M/I/Q 地址精确读写、数据模型以寄存器和位为主的场景。

多厂商统一接入或需要标准化信息建模时考虑 [OPC UA](../opc/用户使用手册.md)；非西门子设备优先 [Modbus](../modbus/用户使用手册.md)。

## 三、快速开始（演示模式，3 步上手）

演示模式**无需任何真实 PLC 与网络连接**：模拟数据由桌面端内置模拟引擎（Rust `DemoAdapter`）生成，默认输出正弦波（也可在数据源配置中更换为随机游走/锯齿/离散档位），经 Tauri IPC 推送给画面。启动桌面应用（`npx tauri dev`）后即可体验完整流程。

**第 1 步：创建数据源实例**

点击工具栏的「🔌 数据源管理」→「＋ 新增数据源」，填写：

- 名称：`内置S7模拟源`（任意）
- 类型：选择 `西门子 S7`
- 连接模式：选择 `演示模式`
- 演示波形：保持默认「跟随默认波形」即可（默认正弦波；也可选随机游走/锯齿斜升/离散档位）。下拉框下方有当前波形的样例小图；点击标签旁的「?」可查看四档波形的图形样例与说明
- 地址：演示模式下不显示连接配置区，无需填写；切换为「真实设备」后，下方连接配置区会显示地址栏与机架/槽号等参数

保存后，列表中即出现该数据源。

**第 2 步：把节点绑定到数据源**

在画布上选中一个节点（如数字标签、指示灯），右侧属性面板切换到「数据绑定」标签页：

- 数据源：下拉选择刚创建的 `内置S7模拟源`
- 点ID：点击「＋ 添加点组」，在弹出的地址生成助手中选择数据区/类型/偏移生成地址（如 DB 区 + REAL + 偏移 0 → `DB1,REAL0`；S7 地址不支持手输，一律经助手产生），演示模式下接受真实格式的 S7 地址并返回模拟值，切换真实模式无需改绑定；需要多个测点时可继续「＋ 添加点组」或「⇪ 导入点位（批量）」；全部点组地位平等，驱动节点显示的画面点在「画面驱动」下拉中选择（缺省首个点组），其余点实时值见节点详情（双击节点打开：运行数据按 DB 块分 tab 展示，每点一行显示 点ID/点名称/值，下一行为点描述，值可点击手动修改）
- 转换函数：留空即可

添加点组并生成地址后，面板底部显示「✅ 已启用数据绑定」。

**第 3 步：观察实时数据**

节点会立即开始刷新，显示一条平滑的正弦波数值（范围约 20~80，每秒更新）；网关监控面板可看到连接状态与点位实时值。

## 四、配置项说明

在「数据源管理」对话框中，西门子 S7 类型需配置：

| 字段 | 说明 | 默认值 | 示例 |
| --- | --- | --- | --- |
| 名称 | 数据源显示名，绑定节点时在下拉框中展示 | — | `堆垛机1号PLC` |
| 类型 | 选择 `西门子 S7` | — | — |
| 连接模式 | 演示模式 / 真实设备 | 演示 | 真实设备 |
| 演示波形 | 仅演示模式：内置模拟引擎的波形档位（以波形形状命名，与协议无关），缺省正弦；字段自带图形样例，点「?」可看各档波形示例 | 正弦波 | `锯齿斜升` |
| 地址 | 仅真实设备模式显示（选「真实设备」后出现在下方连接配置区），PLC 设备地址，`主机` 或 `主机:端口`（端口缺省 102） | — | `192.168.0.10` / `192.168.0.10:1102` |
| 机架号(rack) | PLC 机架（真实设备模式，连接配置区内） | `0` | `0` |
| 槽号(slot) | PLC 槽号（真实设备模式，连接配置区内） | `2` | S7-300/400 常为 `2`；S7-1200/1500 常为 `1` |
| 轮询间隔(ms) | 读取周期（真实设备模式，连接配置区内） | `1000` | `500` |

> rack/slot 填错是 S7 连接失败最常见的原因之一：S7-300/400 默认 rack 0 / slot 2；S7-1200/1500 通常为 rack 0 / slot 1（且需在 TIA 中开启 PUT/GET）。

> 桌面版全部数据源（含 S7）统一由 Rust 网关经 Tauri IPC 接管：真实模式下由 Rust `S7Adapter` 直连 PLC（WebView 不直连）；演示模式则由内置 `DemoAdapter` 生成数据。两种模式前端链路完全一致，切换无需改绑定。

## 五、点ID（PLC 地址）填写规则

点 ID 采用 nodes7 风格地址字符串，**这是 S7 数据源最容易出错的地方**：

| 数据区 | 语法 | 示例 | 说明 |
| --- | --- | --- | --- |
| DB 数据块 | `DB{n},{类型}{偏移}` | `DB1,REAL0` / `DB1,INT4` / `DB1,WORD6` | 类型：REAL/LREAL/INT/WORD/DINT/DWORD/BYTE(B) |
| DB 位 | `DB{n},X{字节}.{位}` | `DB1,X0.0` | 布尔量（X 可省略：`DB1,0.0`） |
| DB 数组 | `DB{n},{类型}{偏移}.{长度}` | `DB1,REAL0.4` | ⏳ 暂不支持（v2 规划，当前会跳过该点） |
| M 区 | `MB` / `MW` / `MD{偏移}` | `MB0` / `MW0` / `MD0` | 字节/字/双字 |
| M 区位 | `M{字节}.{位}` | `M0.0` | 布尔量 |
| I / Q 区 | `IB/IW/ID{n}` / `QB/QW/QD{n}` | `IB0` / `QW2` | 输入/输出 |

⚠️ `DB1,REAL0,1`（三逗号）是非法写法；数组长度用 `.`（如 `DB1,REAL0.4`）。

- 演示模式：点ID可以是任意字符串（含真实格式的 S7 地址），内置模拟引擎会为每个不同的点ID生成一条独立的波形（波形档位由数据源的「演示波形」决定）。
- 接入真实 PLC：点ID必须与 PLC 程序中实际存在的地址对应，非法地址会被跳过（不影响其他点）。

## 六、实际案例：堆垛机状态监控（演示模式开发 → 真实切换）

**场景**：一台 S7-300 控制的堆垛机（IP `192.168.1.20`，rack 0 / slot 2），DB1 中 REAL0 为当前层数、REAL4 为当前列数、X8.0 为运行状态位。

**操作步骤**：

1. 数据源管理 → 新增数据源：名称 `堆垛机1号PLC`，类型 `西门子 S7`，先用**演示模式**；
2. 画布放置堆垛机节点 + 2 个数字标签 + 1 个指示灯，绑定该数据源：
   - 层数：`DB1,REAL0`，转换函数 `(raw) => Math.round(raw)`
   - 列数：`DB1,REAL4`，转换函数同上
   - 运行：`DB1,X8.0`，转换函数 `(raw) => raw ? '运行' : '停止'`
3. 演示模式下验证画面联动与告警逻辑；
4. 切换真实模式：选「真实设备」后在下方连接配置区的「地址」栏填 `192.168.1.20`、机架 `0`、槽号 `2`，监控面板确认连接后即为真实数据。

**预期效果**：三个节点每秒刷新；运行位变化时指示灯随之切换；地址格式从演示到真实全程不变。

## 七、接入自己的 PLC

将地址改为你自己的 PLC 即可，编辑器侧无需其他约定，但 PLC 侧需满足：

1. **网络可达**：PLC 开放 TCP 102 端口（或你在地址栏指定的端口），与运行编辑器的机器在同一网段/已路由。
2. **rack/slot 正确**：S7-300/400 通常 rack 0 / slot 2；S7-1200/1500 通常 rack 0 / slot 1。
3. **S7-1200/1500 访问权限**：在 TIA 中开启该 DB 块的 PUT/GET 访问，或关闭 DB 的「优化访问」（优化 DB 块受协议层限制，无法被传统 S7comm 读取）。
4. **通信资源**：PLC 的 S7 连接数与 PDU 资源有限，测点很多时建议放宽轮询间隔。

无真机联调时，项目 Rust 侧集成测试自带进程内 PLC 模拟器（snap7-server），`cargo test -p gateway-s7` 即可验证完整协议链路（见开发手册「调试与验证」）。

## 八、常见问题

**Q：真实模式连接失败？**
优先核对 rack/slot（S7-300/400 常为 0/2，S7-1200/1500 常为 0/1）与网络可达性；S7-1200/1500 还需在 TIA 中开启 PUT/GET 或对优化访问 DB 块关闭优化。仍失败时查看桌面应用日志的 `gateway_s7` 通道定位。

**Q：节点一直不刷新数据？**
依次检查：① 网关监控面板中该数据源是否显示已连接；② 节点「点ID」是否为合法 S7 地址格式（非法地址会被跳过）；③ 该地址在 PLC 程序中是否真实存在。

**Q：PLC 断开后会自动重连吗？**
会。网关引擎采用指数退避自动重连（2s 起、最长 30s），重连成功后自动恢复轮询读取，无需手动干预。

**Q：浏览器版能连 S7 吗？**
不能。浏览器无法建立 TCP 连接，原 Node WS 网关已退役；请使用桌面版。

**Q：演示模式的点位格式和真实模式一样吗？**
一样。演示模式接受相同格式的点 ID 并返回模拟值，切换真实模式无需改绑定。

**Q：一个数据源能被多个节点共用吗？**
可以。多个节点绑定同一个数据源实例时，编辑器内部只建立一条 PLC 连接，按各自点ID分别订阅（同一轮批量读取），互不影响。

## 九、注意事项

- 轮询间隔最小 200ms；S7 PLC 通信资源（连接数/PDU）有限，测点多时建议放宽间隔。
- rack/slot、PUT/GET 设置错误是真实连接失败主因，切换真实模式前先与电气工程师核对。
- S7comm 无内建加密，关键场景建议置于隔离工业网络。
- 技术实现细节见 [S7 数据源开发手册](./S7%20数据源开发手册.md)。
