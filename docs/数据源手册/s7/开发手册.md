# 西门子 S7 数据源 · 开发手册

> 面向维护、调试或扩展 S7 数据接入的开发者。数据源类型标识：`s7`。

## 一、架构与数据流

S7comm 为原生 TCP 二进制协议，浏览器无法直连，需经独立 WS 网关桥接。系统提供两条链路（订阅协议一致）：

```
演示模式：
  X6 节点 ── S7Service ──WS──▶ 内置演示网关 mock/server.ts (8084 /s7) ──▶ s7Value() 模拟数据

真实模式：
  X6 节点 ── S7Service ──WS──▶ 独立网关 gateway/s7-gateway.ts (19101 /s7)
                                      │ nodes7 (S7comm over TCP)
                                      ▼
                              真实 PLC / 仿真端 gateway/s7-simulator.ts (19503)
```

前端 → 网关协议：`{action:'configure',config}` / `{action:'subscribe',topic}` / `{action:'unsubscribe',topic}`；网关 → 前端：`{type:'status',connected,message}` 与 `{topic,value,timestamp,quality}`。

## 二、核心类型定义

`src/services/S7Service.ts` 定义设备配置：

```ts
export interface S7DeviceConfig {
    host?: string          // PLC 主机地址
    port?: number          // S7comm 端口（默认 102）
    rack?: number          // 机架号（默认 0）
    slot?: number          // 槽号（S7-300/400 默认 2，S7-1200/1500 通常 1）
    pollInterval?: number  // 轮询间隔毫秒（默认 1000）
    demo?: boolean         // true=内置演示网关，false=独立真实网关
}
```

复用统一 `DataPoint` / `IDataService` / `DataBindingConfig`。数据源实例 `DataSource.type='s7'`，`config` 即上述设备参数（随数据源持久化）。

## 三、前端 Service 实现

`src/services/S7Service.ts`：`S7Service(url, config={})`，构造即连接。与 WebSocketService 的差异在于 **onopen 时先下发 configure 再重订阅**，并处理网关 `status` 帧：

```ts
this.ws.onopen = () => {
    this.isConnected_ = true
    this.sendConfigure()                       // 真实网关据此连设备；演示网关忽略
    for (const [pointId] of this.callbacks) this.sendSubscribe(pointId)
}
this.ws.onmessage = (event) => {
    const data = JSON.parse(event.data)
    if (data.type === 'status') {              // 网关设备连接结果
        data.connected ? console.log('[S7] 设备已连接') : console.warn('[S7] 设备未连接')
        return
    }
    const pointId = data.topic || data.id || data.pointId
    if (pointId && this.callbacks.has(pointId)) {
        const point = { id: pointId, value: data.value ?? data.data, timestamp: data.timestamp || Date.now(), quality: data.quality || 'good' }
        for (const cb of this.callbacks.get(pointId) || []) cb(point)
    }
}
```

`sendConfigure()` 发送 `{ action:'configure', config: this.config }`。自动重连（3s）、重连后重发 configure + 重订阅。

## 四、数据格式与点ID约定

点ID为 nodes7 地址字符串：`DB1,REAL0` / `DB1,INT4` / `DB1,WORD6` / `DB1,X0.0`（位）/ `MB0`/`MW0`/`MD0`/`MR0`（M 区）/ `IB0`/`QB0`。

⚠️ `DB1,REAL0,1`（三逗号）非法，nodes7 会因「String Couldn't Split Properly」静默丢弃该点；数组长度用 `.`（如 `DB1,REAL0.4`）。

## 五、内置演示网关

`mock/server.ts` 的 `startS7Server()`，监听 `ws://localhost:8084/s7`，与 WS 服务相同的订阅协议，每秒推送 `s7Value()`（忽略设备配置）：

```ts
const wss = new WebSocketServer({ port: MOCK_PORTS.s7, path: '/s7' })
// 收到 subscribe/unsubscribe 维护 clientPoints，每秒推送：
ws.send(JSON.stringify({ topic: pointId, value: s7Value(pointId, t), timestamp: t, quality: 'good' }))
```

数据算法（`mock/generators.ts`）——PLC 设定值阶梯跟踪，每 5s 换目标平滑逼近 + 微噪声，0~100：

```ts
export function s7Value(pointId: string, t: number): number {
  const step = Math.floor(t / 5000)
  const target = 10 + ((hashInt(pointId) + step * 17) % 80)
  const frac = (t % 5000) / 5000
  const prevTarget = 10 + ((hashInt(pointId) + (step - 1) * 17) % 80)
  const base = prevTarget + (target - prevTarget) * frac
  const noise = (Math.random() - 0.5) * 3
  return round1(Math.max(0, Math.min(100, base + noise)))
}
```

## 六、独立真实网关

`gateway/s7-gateway.ts`，`WebSocketServer({ port: 19101, path: '/s7' })`（`GATEWAY_S7_PORT` 可覆盖）。每个 WS 连接对应一个设备会话，收到 configure 后用 **nodes7** 连接 PLC：

```ts
import NodeS7 from 'nodes7'
const conn = new NodeS7({ silent: true })
const params = { host, port, rack, slot, doNotOptimize: true }  // doNotOptimize：每点独立读取
conn.initiateConnection(params, (err) => {
    if (err) { send(ws, { type:'status', connected:false, message: err }); return }
    s.connected = true
    send(ws, { type:'status', connected:true, message:'设备已连接' })
    for (const p of s.points) if (!s.added.has(p)) { conn.addItems(p); s.added.add(p) }  // 补发已订阅点
    ensurePolling(s)
})
```

订阅/取消同步调用 nodes7：

```ts
if (msg.action === 'subscribe') { session.points.add(msg.topic); if (connected) { conn.addItems(msg.topic); added.add(...) } }
else if (msg.action === 'unsubscribe') { session.points.delete(msg.topic); if (connected) conn.removeItems(msg.topic) }
```

周期读取（`readAllItems`，间隔 `Math.max(200, pollInterval||1000)`）：

```ts
s.timer = setInterval(() => {
    if (!s.connected || s.reading) return
    s.reading = true
    const t = Date.now()
    s.conn.readAllItems((bad, values) => {
        s.reading = false
        for (const pointId of s.points) {
            const v = values ? values[pointId] : undefined
            send(s.ws, v === undefined
                ? { topic: pointId, value: null, timestamp: t, quality: 'bad' }
                : { topic: pointId, value: v, timestamp: t, quality: 'good' })
        }
    })
}, interval)
```

config 默认值：`host 127.0.0.1 / port 102 / rack 0 / slot 2 / pollInterval 1000`。关闭用 `conn.dropConnection()`。

## 七、仿真 PLC（纯 JS 实现 S7comm）

`gateway/s7-simulator.ts`，用 `node:net` 手写 S7comm 协议栈（TPKT/COTP/S7 PDU），监听 19503（`SIM_S7_PORT`）。从 nodes7 源码逆向出字节格式：

- COTP 连接请求(CR/0xE0) → 连接确认(CC/0xD0)
- S7 Setup Communication(0xF0) → 协商 PDU=960
- S7 Read Var(0x04) → 按请求字节长度返回模拟值

读取请求项解析与按长度编码：

```ts
const byteLen = req.readUInt16BE(off + 4)
const dbNumber = req.readUInt16BE(off + 6)
const addr32 = req.readUInt32BE(off + 8)
const area = addr32 >>> 24
const byteOffset = (addr32 & 0x00ffffff) >>> 3
const seed = area * 100000 + dbNumber * 1000 + byteOffset   // 不同点波形各异

function encodeValue(seed, byteLen, t) {
  const v = triangle(seed, t)                               // 三角波 100~900，12s 周期
  const buf = Buffer.alloc(byteLen)
  if (byteLen === 1) buf.writeUInt8(Math.round(v) & 0xff, 0)   // BYTE
  else if (byteLen === 2) buf.writeInt16BE(Math.round(v), 0)   // INT16
  else if (byteLen === 4) buf.writeFloatBE(v, 0)               // IEEE-754 REAL
  return buf
}
```

响应必须回显请求的 PDU ref（请求字节 11-12）作为序列号，否则 nodes7 无法匹配。

## 八、路由与节点绑定机制

`useDataService.ts`：

```ts
case 's7':
    service = new S7Service(sourceUrl, sourceConfig)   // 透传设备配置
    break
```

缓存键含 `JSON.stringify(config)`，同地址不同设备参数会创建不同服务。数据源解析：节点 `binding.sourceId` → store 取出 `ds.type/url/config`。

## 九、扩展指南

- **支持写操作**：当前只读。可在网关增加 `{action:'write',topic,value}`，调用 nodes7 `writeItems`，并在 Service/绑定层暴露下发接口。
- **批量优化**：`doNotOptimize:true` 让每点独立读取（便于仿真按长度编码）；连真实 PLC 且点多时可去掉该选项让 nodes7 合并请求提升吞吐。
- **新增数据区**：nodes7 已支持 DB/M/I/Q；如需定时器/计数器等特殊区，参考 nodes7 地址语法扩展。
- **修改仿真数据**：编辑 `s7-simulator.ts` 的 `triangle()`/`encodeValue()`，或 `generators.ts` 的 `s7Value()`（演示网关）。

## 十、调试与验证

1. 启动仿真链路：

```bash
npm run s7-simulator    # 19503 仿真 PLC
npm run s7-gateway      # 19101 网关
```

2. 浏览器控制台动态验证（经网关连仿真端）：

```js
const { S7Service } = await import('http://localhost:5173/src/services/S7Service.ts')
const svc = new S7Service('ws://localhost:19101/s7', { host:'127.0.0.1', port:19503, rack:0, slot:2, pollInterval:300, demo:false })
svc.subscribe('DB1,REAL0', p => console.log(p.value, p.quality))
// 输出上升浮点序列，quality good；验证完 svc.disconnect()
```

3. 环境变量：`GATEWAY_S7_PORT`（网关）、`SIM_S7_PORT`/`SIM_S7_HOST`（仿真）。
