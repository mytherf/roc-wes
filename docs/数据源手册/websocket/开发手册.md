# WebSocket 数据源 · 开发手册

> 面向需要维护、调试或扩展 WebSocket 数据接入的开发者。数据源类型标识：`websocket`。

## 一、架构与数据流

WebSocket 是浏览器原生协议，前端 Service 直接与服务端建立长连接，**不经过任何网关**：

```
┌────────────┐  subscribe(topic)   ┌──────────────────┐
│ X6 节点     │ ──────────────────▶ │ WebSocketService │
│ node.data   │                     │  (src/services)  │
│  .value     │ ◀────────────────── │                  │ ◀══ WS 长连接 ══▶  服务端
└────────────┘  DataPoint 回调      └──────────────────┘   {topic,value,...}
       ▲
       │ useDataService.bindNodeData() 订阅并把值写入 node.data.value
```

数据流向：`useDataService` 按数据源类型创建/缓存 Service → 节点绑定时调用 `service.subscribe(pointId, cb)` → Service 通过 WS 发送订阅帧 → 服务端推送数据帧 → Service 解析为 `DataPoint` 回调 → 回调把值写入 `node.data.value` 并触发节点事件评估。

## 二、核心类型定义

所有数据源服务都实现统一接口（`src/services/DataService.ts`）：

```ts
export interface DataPoint {
    id: string                       // 数据点唯一标识
    value: number | string
    timestamp: number
    quality?: 'good' | 'bad' | 'uncertain'
}

export type DataCallback = (point: DataPoint) => void

export interface IDataService {
    subscribe(pointId: string, callback: DataCallback): void
    unsubscribe(pointId: string): void
    isConnected(): boolean
    disconnect(): void
}
```

节点侧的绑定配置（存储在节点 `data.binding`）：

```ts
export interface DataBindingConfig {
    pointId: string                 // 用于订阅的数据点 ID
    sourceId?: string               // 引用「数据源管理」中的实例；为空则用模拟数据
    sourceType?: 'websocket' | 'mqtt' | 'http' | 'sse' | 's7' | 'opc' | 'modbus'
    sourceUrl?: string              // 兼容旧数据
    transform?: (raw: any) => number | string
    interval?: number               // 仅 HTTP 轮询有效
}
```

数据源实例（`src/stores/dataSource.ts`）：

```ts
export interface DataSource {
    id: string
    name: string
    type: DataSourceType            // 'websocket' | ...
    url: string
    description?: string
    config?: Record<string, any>    // 协议特定参数（WebSocket 通常为空）
}
```

## 三、前端 Service 实现

文件：`src/services/WebSocketService.ts`。构造即连接，支持多主题订阅与自动重连。

关键机制：

```ts
constructor(url: string) {
    this.url = url
    this.connect()
}

private connect() {
    this.ws = new WebSocket(this.url)
    this.ws.onopen = () => {
        this.isConnected_ = true
        // 重连后重新订阅之前的所有主题
        for (const [topic] of this.callbacks) this.sendSubscribe(topic)
    }
    this.ws.onmessage = (event) => {
        const data = JSON.parse(event.data)
        const pointId = data.topic || data.id || data.pointId
        if (pointId && this.callbacks.has(pointId)) {
            const point: DataPoint = {
                id: pointId,
                value: data.value ?? data.data,
                timestamp: data.timestamp || Date.now(),
                quality: data.quality || 'good',
            }
            for (const cb of this.callbacks.get(pointId) || []) cb(point)
        }
    }
    this.ws.onclose = () => { this.isConnected_ = false; this.scheduleReconnect() }
}
```

订阅/取消订阅帧：

```ts
private sendSubscribe(topic: string) {
    if (this.ws?.readyState === WebSocket.OPEN)
        this.ws.send(JSON.stringify({ action: 'subscribe', topic }))
}
```

要点：

- **回调表**：`callbacks: Map<pointId, DataCallback[]>`，同一点可被多个节点订阅。
- **自动重连**：`onclose` 后 `scheduleReconnect()`，固定 3s（`reconnectDelay = 3000`）重试；`onopen` 时遍历 `callbacks` 重新下发订阅，保证重连后数据恢复。
- **字段兼容**：点ID取 `topic||id||pointId`，数值取 `value??data`，便于对接不同后端。
- `disconnect()` 会清除重连定时器、关闭连接并清空回调表。

## 四、数据格式与点ID约定

| 方向 | 报文 | 说明 |
| --- | --- | --- |
| 前端 → 服务端 | `{ "action": "subscribe", "topic": "<pointId>" }` | 订阅 |
| 前端 → 服务端 | `{ "action": "unsubscribe", "topic": "<pointId>" }` | 取消订阅 |
| 服务端 → 前端 | `{ "topic", "value", "timestamp"?, "quality"? }` | 数据帧 |

点ID即订阅主题，无格式约束，需与服务端一致。

## 五、内置模拟服务

文件：`mock/server.ts` 的 `startWsServer()`，开发环境由 `vite.config.ts` 的 mock 插件随 `npm run dev` 自动启动，监听 `ws://localhost:8080/ws`（path `/ws`）。

服务端为每个连接维护一个 topic 集合，每秒推送：

```ts
const wss = new WebSocketServer({ port: MOCK_PORTS.ws, path: '/ws' })
const clientTopics = new Map<any, Set<string>>()
wss.on('connection', (ws) => {
    clientTopics.set(ws, new Set())
    ws.on('message', (raw) => {
        const msg = JSON.parse(raw.toString())
        const topics = clientTopics.get(ws)
        if (msg.action === 'subscribe' && msg.topic) topics.add(msg.topic)
        else if (msg.action === 'unsubscribe' && msg.topic) topics.delete(msg.topic)
    })
    ws.on('close', () => clientTopics.delete(ws))
})
setInterval(() => {
    const t = Date.now()
    for (const [ws, topics] of clientTopics) {
        if (ws.readyState !== ws.OPEN) continue
        for (const topic of topics)
            ws.send(JSON.stringify({ topic, value: wsValue(topic, t), timestamp: t, quality: 'good' }))
    }
}, 1000)
```

数据生成算法（`mock/generators.ts`）——平滑正弦波 + 微小噪声，范围约 20~80：

```ts
export function wsValue(pointId: string, t: number): number {
  const phase = hashPhase(pointId)   // 由 pointId 哈希出 0~2π 相位，错开各点波形
  return round1(50 + 30 * Math.sin(t / 5000 + phase) + (Math.random() - 0.5) * 2)
}
```

## 六、路由与节点绑定机制

`src/composables/useDataService.ts` 按类型路由并缓存服务实例：

```ts
case 'websocket':
    service = new WebSocketService(sourceUrl)
    break
```

缓存键为 `${sourceType}:${sourceUrl}:${JSON.stringify(config)}`，同一数据源只建一条连接。节点绑定时：

```ts
service.subscribe(binding.pointId, (point) => {
    let newValue = point.value
    if (binding.transform) newValue = binding.transform(point.value)
    node.setData({ ...node.getData(), value: newValue, _timestamp: point.timestamp, _quality: point.quality })
    evaluateNodeEvents(node.id, currentData, nextData)   // 触发比较类事件（上升沿）
})
```

即数据点更新会自动写入 `node.data.value`（附带 `_timestamp`/`_quality`），并驱动节点事件评估。

## 七、扩展指南

- **修改模拟数据特征**：编辑 `mock/generators.ts` 的 `wsValue()`（如改为方波、叠加趋势项）。
- **新增推送字段**：在 `WebSocketService.onmessage` 的 `DataPoint` 组装处扩展，并同步 `DataPoint` 接口。
- **支持自定义订阅协议**：若你的后端订阅帧不是 `{action,topic}`，可在 `sendSubscribe()` 中适配，或派生一个新的 Service 并在 `useDataService` 的 switch 中注册新类型。
- **调整重连策略**：修改 `reconnectDelay`，或引入指数退避（在 `scheduleReconnect` 中累加延时）。

## 八、调试与验证

1. 启动开发环境：`npm run dev`，控制台应出现 `[mock] WebSocket 服务已启动: ws://localhost:8080/ws`。
2. 浏览器控制台动态导入验证（无需操作画布）：

```js
const { WebSocketService } = await import('http://localhost:5173/src/services/WebSocketService.ts')
const svc = new WebSocketService('ws://localhost:8080/ws')
svc.subscribe('sensor.temp.001', p => console.log(p.value, p.quality))
// 观察每秒输出的正弦波数值；验证完 svc.disconnect()
```

3. 用 `wscat` 手工验证服务端：

```bash
wscat -c ws://localhost:8080/ws
> {"action":"subscribe","topic":"sensor.temp.001"}
< {"topic":"sensor.temp.001","value":53.2,"timestamp":1730000000000,"quality":"good"}
```
