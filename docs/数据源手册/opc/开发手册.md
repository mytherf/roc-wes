# OPC UA 数据源 · 开发手册

> 面向维护、调试或扩展 OPC UA 数据接入的开发者。数据源类型标识：`opc`。

## 一、架构与数据流

OPC UA 默认 `opc.tcp://` 二进制协议，浏览器无法直连，需经独立 WS 网关桥接（node-opcua 客户端）。两条链路订阅协议一致：

```
演示模式：
  X6 节点 ── OpcService ──WS──▶ 内置演示网关 mock/server.ts (8085 /opc) ──▶ opcValue() 模拟数据

真实模式：
  X6 节点 ── OpcService ──WS──▶ 独立网关 gateway/opc-gateway.ts (19102 /opc)
                                      │ node-opcua OPCUAClient (opc.tcp)
                                      ▼
                          真实服务器 / 仿真端 gateway/opc-simulator.ts (19504)
```

前端 → 网关：`{action:'configure',config}` / `{action:'subscribe',topic}` / `{action:'unsubscribe',topic}`；网关 → 前端：`{type:'status',connected,message}` 与 `{topic,value,timestamp,quality}`。

## 二、核心类型定义

`src/services/OpcService.ts` 定义设备配置：

```ts
export interface OpcDeviceConfig {
    endpoint?: string      // 端点 URL（如 opc.tcp://127.0.0.1:4840），优先于 host/port
    host?: string          // 未填 endpoint 时与 port 拼接
    port?: number          // 默认 4840
    pollInterval?: number  // 默认 1000
    demo?: boolean         // true=内置演示网关，false=独立真实网关
}
```

复用统一 `DataPoint` / `IDataService` / `DataBindingConfig`。数据源实例 `DataSource.type='opc'`，`config` 即上述参数。

## 三、前端 Service 实现

`src/services/OpcService.ts`：`OpcService(url, config={})`，结构与 S7Service 一致——onopen 先 `sendConfigure()` 再重订阅，处理网关 `status` 帧，3s 自动重连。`sendConfigure()` 发送 `{ action:'configure', config: this.config }`。数据帧按 `topic||id||pointId` 匹配回调，数值取 `value??data`。

## 四、数据格式与点ID约定

点ID为 OPC UA NodeId 字符串：`ns=2;s=Ramp`（字符串标识）或 `ns=2;i=1001`（数值标识）。`ns` 为命名空间索引，须与服务器一致。

## 五、内置演示网关

`mock/server.ts` 的 `startOpcServer()`，监听 `ws://localhost:8085/opc`，与 WS 服务相同订阅协议，每秒推送 `opcValue()`（忽略设备配置）：

```ts
const wss = new WebSocketServer({ port: MOCK_PORTS.opc, path: '/opc' })
// 维护 clientPoints，每秒推送：
ws.send(JSON.stringify({ topic: pointId, value: opcValue(pointId, t), timestamp: t, quality: 'good' }))
```

数据算法（`mock/generators.ts`）——量化阶梯（保持-跳变），每 4s 跳变到 5 的整数倍档位（0~100）：

```ts
export function opcValue(pointId: string, t: number): number {
  const step = Math.floor(t / 4000)
  const level = (hashInt(pointId) + step * 7) % 21   // 0~20 档
  return level * 5
}
```

## 六、独立真实网关

`gateway/opc-gateway.ts`，`WebSocketServer({ port: 19102, path: '/opc' })`（`GATEWAY_OPC_PORT` 可覆盖）。端点归一化：

```ts
function resolveEndpoint(c: any): string {
  if (c.endpoint && String(c.endpoint).trim()) return String(c.endpoint).trim()
  const host = c.host || '127.0.0.1'
  const port = Number(c.port) || 4840
  return `opc.tcp://${host}:${port}`
}
```

用 **node-opcua** 连接并创建会话：

```ts
import { OPCUAClient, MessageSecurityMode, SecurityPolicy } from 'node-opcua'
const client = OPCUAClient.create({
  endpointMustExist: false,
  keepSessionAlive: true,
  securityMode: MessageSecurityMode.None,      // 本地/内网仿真；生产可扩展证书签名
  securityPolicy: SecurityPolicy.None,
  connectionStrategy: { initialDelay: 500, maxRetry: 1 },
})
await client.connect(s.config.endpoint)
const session = await client.createSession()
```

读节点（轮询间隔 `Math.max(200, pollInterval||1000)`）：

```ts
async function readPoint(session, pointId) {
  const dataValue = await session.readVariableValue(pointId)
  if (dataValue.statusCode?.isNotGood?.()) throw new Error(`节点状态异常: ${dataValue.statusCode}`)
  return dataValue.value?.value
}
// 轮询：成功发 {topic,value,timestamp,quality:'good'}；失败发 {topic,value:null,quality:'bad',error}
```

关闭：`await session.close()` + `await client.disconnect()`。

## 七、仿真 OPC UA 服务器

`gateway/opc-simulator.ts`，node-opcua `OPCUAServer`，监听 19504（`SIM_OPC_PORT`），resourcePath `/UA/Simulator`，匿名访问：

```ts
const server = new OPCUAServer({ port: PORT, resourcePath: '/UA/Simulator', allowAnonymous: true, buildInfo: {...} })
await server.initialize()
const addressSpace = server.engine.addressSpace!
// 关键：用 registerNamespace 注册自定义命名空间（索引 2），不能用 getNamespaceIndex(2)（默认不存在会断言失败）
const namespace = addressSpace.registerNamespace('urn:roc-wes:opc-simulator')
const folder = namespace.addFolder(addressSpace.rootFolder.objects, { browseName: 'Simulator' })

// getter 模式实时计算（时变值）
namespace.addVariable({ componentOf: folder, browseName: 'Ramp', nodeId: 's=Ramp', dataType: 'Double',
  value: { get: () => new Variant({ dataType: DataType.Double, value: ramp(Date.now()) }) } })
// ... Sine / Triangle / Counter(Int32) / Status(Boolean)
```

暴露节点：`ns=2;s=Ramp`（0~100 锯齿）、`Sine`（0~100 正弦）、`Triangle`（100~900 三角波）、`Counter`（Int32 每秒+1）、`Status`（Boolean 每3s翻转）。

## 八、路由与节点绑定机制

`useDataService.ts`：

```ts
case 'opc':
    service = new OpcService(sourceUrl, sourceConfig)
    break
```

缓存键含 `JSON.stringify(config)`。节点 `binding.sourceId` → store 解析 `ds.type/url/config`。

## 九、扩展指南

- **改用订阅（Subscription）推送**：当前为轮询 `readVariableValue`。可用 node-opcua 的 `session.createSubscription` + `MonitorItem` 实现事件驱动推送，降低延迟与轮询开销。
- **启用安全策略**：生产环境配置 `securityMode: SignAndEncrypt`、`securityPolicy: Basic256Sha256`，并提供客户端证书（`OPCUAClient.create({ certificateFile, privateKeyFile })`）。
- **批量读取**：多点可用 `session.read(nodesToRead)` 一次读取多个 NodeId 提升吞吐。
- **修改仿真数据/节点**：编辑 `opc-simulator.ts` 的 `addVariable` 与 `ramp/sine/triangle` 算法；演示网关数据改 `generators.ts` 的 `opcValue()`。

## 十、调试与验证

1. 启动仿真链路：

```bash
npm run opc-simulator   # opc.tcp://127.0.0.1:19504/UA/Simulator
npm run opc-gateway     # 19102 网关
```

2. 浏览器控制台动态验证：

```js
const { OpcService } = await import('http://localhost:5173/src/services/OpcService.ts')
const svc = new OpcService('ws://localhost:19102/opc', { endpoint:'opc.tcp://127.0.0.1:19504', pollInterval:300, demo:false })
svc.subscribe('ns=2;s=Triangle', p => console.log(p.value, p.quality))
// 输出 100~900 三角波，quality good；验证完 svc.disconnect()
```

3. 用 UaExpert 直连 `opc.tcp://127.0.0.1:19504/UA/Simulator` 浏览节点树，核对 NodeId。
4. 环境变量：`GATEWAY_OPC_PORT`（网关）、`SIM_OPC_PORT`/`SIM_OPC_HOST`（仿真）。
