# OPC UA 数据源 · 开发手册

> 面向维护、调试或扩展 OPC UA 数据接入的开发者。数据源类型标识：`opc` ｜ 桌面版真实模式：⏳ 适配器待实现（factory 返回 `Unsupported`）

## 一、现状与架构预留

桌面版已为 OPC UA 打通「配置 → IPC → 工厂」的全部管道，仅缺适配器实现：

```
前端已就绪：
  DataSourceDeviceConfig（endpoint/pollInterval）
      ──▶ deviceConfig.ts buildDeviceConfig('opc') → { kind:'opc', endpoint, pollIntervalMs }
      ──▶ IpcGatewayService ──IPC──▶ gateway_connect

Rust 已就绪：
  gateway-core/src/config.rs  OpcConfig { endpoint, poll_interval_ms:1000 }
  factory.rs  DeviceConfig::Opc(_) → Err(Unsupported("OPC UA 适配器待引入 opcua crate"))

缺口：
  crates/gateway-opcua（实现 trait DeviceAdapter）
```

演示模式已可用：`config` 判定为 demo 时映射 `{ kind:'demo' }`，由 `gateway-demo` 生成模拟曲线（NodeId 原样接受，不做格式校验）。

前端 WS 网关桥接实现（原 `OpcService`）已随纯桌面化改造移除（可从 git 历史找回）；内置 Node 网关（`gateway/opc-gateway.ts`，19102）、仿真服务器（`gateway/opc-simulator.ts`，19504）与 mock 桥接（8085）也已退役。

## 二、点 ID 约定

点 ID 为 OPC UA NodeId 字符串，适配器按原样解析：

| 形式 | 示例 |
| --- | --- |
| 字符串标识 | `ns=2;s=Ramp` |
| 数字标识 | `ns=2;i=1001` |

后续可扩展支持完整 NodeId 语法（`g=` GUID、`b=` Base64）；解析失败应返回 `InvalidPoint`，单点失败不影响其他点（与 Modbus 适配器行为一致）。

## 三、技术方案（opcua crate）

路线图上排在 S7 spike 之后，核心决策：

| 项 | 方案 |
| --- | --- |
| 客户端库 | Rust `opcua` crate（纯 Rust 实现） |
| 首版读取模型 | 轮询 `Read` 服务（与引擎轮询模型天然对齐，实现最简） |
| 演进方向 | `Subscription + MonitoredItem` 事件驱动推送（降低延迟与开销；需引擎支持「适配器主动推送」语义，属引擎层小改造） |
| 安全策略 | 首版支持匿名 + SecurityPolicy None，与旧 Node 实现行为对齐；证书/加密作为后续配置项 |

验收标准建议：对 KEPServerEX（或 `opcua` 自带样例服务器）跑通字符串/数字 NodeId 读取、坏点质量戳透传（`quality: 'bad'`），纳入 `gateway-engine` 集成测试同构的测试集。

## 四、落地步骤（对照 Modbus 样板）

1. `crates/gateway-opcua`：`OpcuaAdapter` 实现 `trait DeviceAdapter`——`connect` 建立会话（端点发现/匿名认证），`read` 批量 Read 各 NodeId 并把 `DataValue` 的 value/statusCode/sourceTimestamp 映射为 `Telemetry`（质量戳：Good→good，Bad→bad，Uncertain→uncertain），`kind()` 返回 `"opc"`；
2. `src-tauri/Cargo.toml` 添加 `gateway-opcua` 依赖（工作区 `crates/*` 自动纳管）；
3. `factory.rs`：把 `DeviceConfig::Opc` 分支替换为 `Box::new(gateway_opcua::OpcuaAdapter::new(cfg))`（引擎、命令层、前端零改动）；
4. 测试：NodeId 解析单测 + 会话集成测试（可先以内存 fake server 验证会话/读取交互）；
5. 更新本文档状态为已上线，并同步 [用户使用手册](./用户使用手册.md) 的现状表与总索引。

pub struct OpcConfig {
