# OPC UA 数据源 · 用户使用手册

> 适用版本：roc-wes（桌面版） ｜ 数据源类型标识：`opc` ｜ 桌面版真实模式：✅ 已上线

## 一、简介

OPC UA（OPC Unified Architecture）是工业互联的「通用语言」，一套跨平台、跨厂商的标准数据访问规范。它把设备数据抽象为带类型、带质量戳、带时间戳的「节点（Node）」，并支持复杂的安全机制与信息建模。越来越多的 PLC、SCADA、MES 都提供 OPC UA 服务器接口，是新建智能工厂的主流选择。

OPC UA 默认走 `opc.tcp://` 二进制协议，**浏览器无法直接连接**。桌面版由内置 Rust 网关原生连接 OPC UA 服务器（无需中间网关进程）；画面开发阶段也可先用**演示模式**完成全部联动验证，随后一键切换真实模式。

## 二、现状说明（重要）

| 能力 | 状态 |
| --- | --- |
| 演示模式（桌面版） | ✅ 可用：内置模拟曲线，任意 NodeId 均返回模拟值 |
| 真实模式（桌面版） | ✅ 可用：Rust 原生 OPC UA 客户端（匿名 + SecurityPolicy None）轮询读取 |
| 浏览器版 | ❌ 无法连接（浏览器无原生 TCP，内置 Node 网关已退役） |

推荐工作流：**演示模式开发画面 → 一键切换真实模式**（NodeId 与端点配置格式保持不变）。技术实现见 [开发手册](./开发手册.md)。

## 三、适用场景

- 多厂商设备统一接入（西门子、罗克韦尔、倍福、欧姆龙等均有 OPC UA 方案）。
- 需要标准化信息模型、类型与安全机制的场景。
- 已有 OPC UA 服务器（如 KEPServerEX、设备自带 UA Server）。

仅接西门子且按寄存器建模更顺手时用 [S7](../s7/用户使用手册.md)；简单仪表/变频器优先 [Modbus](../modbus/用户使用手册.md)。

## 四、快速开始（演示模式，3 步上手）

**第 1 步：创建数据源**

「🔌 数据源管理」→「＋ 新增数据源」：

- 名称：`内置OPC模拟源`
- 类型：`OPC UA`
- 连接模式：演示模式

**第 2 步：绑定节点**

选中节点 → 「数据绑定」标签页：

- 数据源：`内置OPC模拟源`
- 点ID：`ns=2;s=Ramp`（演示模式下任意 NodeId 都返回模拟值）
- 转换函数：留空

**第 3 步：观察数据**

节点显示按周期变化的模拟数值；网关监控面板可看到连接状态与点位实时值。

## 五、配置项说明

真实模式需配置（端点地址与其他协议一样统一填在「地址」栏）：

| 字段 | 说明 | 默认值 | 示例 |
| --- | --- | --- | --- |
| 连接模式 | 演示模式 / 真实设备 | 演示 | 真实设备 |
| 地址 | OPC UA 服务器端点 URL（真实模式必填） | — | `opc.tcp://192.168.0.50:4840` |
| 轮询间隔(ms) | 读取周期 | `1000` | `500` |

> 端点 URL 以服务器实际公布为准；部分服务器带资源路径（如 `opc.tcp://host:4840/UA/Server`）。

## 六、点ID（NodeId）填写规则

点 ID 为 OPC UA NodeId 字符串，常见形式：

| 形式 | 示例 | 说明 |
| --- | --- | --- |
| 字符串标识 | `ns=2;s=Ramp` | `ns=` 命名空间索引 + `s=` 字符串 ID，最常用 |
| 数字标识 | `ns=2;i=1001` | 数字型 NodeId |

真实模式要求显式 `ns=` 段；GUID（`g=`）与 ByteString（`b=`）形式暂不支持，非法 NodeId 会被跳过并告警（不影响其他点）。

NodeId 必须与服务器节点树中的实际标识一致（可用 UaExpert 等客户端浏览节点树核对）。

## 七、实际案例：车间能耗看板（演示模式开发 → 真实切换）

**场景**：车间 OPC UA 服务器（`opc.tcp://192.168.1.100:4840`）暴露 `ns=2;s=Power.Total`（总功率 kW）、`ns=2;s=Power.Line1`（1号线功率）。

**操作步骤**：

1. 数据源管理 → 新增：名称 `车间OPC服务器`，类型 `OPC UA`，先用**演示模式**；
2. 画布放置 2 个 Gauge 仪表盘节点，绑定该数据源：
   - 总功率：`ns=2;s=Power.Total`，转换函数 `(raw) => raw.toFixed(1)`
   - 1号线：`ns=2;s=Power.Line1`，转换函数同上
3. 演示模式下验证仪表盘动画与阈值告警；
4. 切换真实模式：在「地址」栏填端点 `opc.tcp://192.168.1.100:4840`，监控面板确认连接后即为真实数据。

## 八、常见问题

**Q：真实模式连接失败？**
优先核对端点 URL（以服务器实际公布为准，部分服务器带资源路径）、服务器是否允许匿名访问与 SecurityPolicy None；仍失败时查看网关日志（`gateway_opcua` 通道）定位。

**Q：浏览器版能连 OPC UA 吗？**
不能。浏览器无法建立 TCP 连接，原 Node WS 网关已退役；请使用桌面版。

**Q：演示模式的 NodeId 有格式校验吗？**
没有。演示模式接受任意字符串并返回模拟值；真实模式会校验 NodeId 格式（`ns={n};s=` / `ns={n};i=`），非法点位跳过并告警。

## 九、注意事项

- 轮询间隔最小 200ms；OPC UA 服务器会话资源有限，测点多时建议放宽间隔（后续版本将评估订阅推送模式）。
- 首版为匿名认证 + SecurityPolicy None（与旧实现行为对齐）；证书/加密安全策略作为后续配置项演进。
- 生产环境建议启用 OPC UA 内建安全机制（证书 + 加密）。
