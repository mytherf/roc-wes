# SSE 数据源 · 开发手册

> 面向维护、调试或扩展 SSE 数据接入的开发者。数据源类型标识：`sse`。

## 一、架构与数据流

SSE 基于浏览器原生 `EventSource`，**无网关**，每个数据点一条独立的 SSE 连接：

```
┌────────────┐  subscribe(pointId)  ┌─────────────┐  EventSource url?pointId=x  ┌────────────┐
│ X6 节点     │ ───────────────────▶ │ SseService  │ ──────────────────────────▶ │ SSE 接口    │
│ node.data   │                      │ 每点一个      │ ◀════ text/event-stream ═══ │            │
│  .value     │ ◀─────────────────── │ EventSource │   data: {json}\n\n          └────────────┘
└────────────┘   DataPoint 回调       └─────────────┘   （浏览器自动重连）
```

## 二、核心类型定义

复用统一的 `DataPoint` / `IDataService` / `DataBindingConfig`（`src/services/DataService.ts`）。数据源实例 `DataSource.type = 'sse'`，`config` 通常为空。

## 三、前端 Service 实现

文件：`src/services/SseService.ts`。

```ts
subscribe(pointId: string, callback: DataCallback): void {
    if (!this.callbacks.has(pointId)) this.callbacks.set(pointId, [])
    this.callbacks.get(pointId)!.push(callback)

    if (!this.sources.has(pointId)) {
        const sep = this.url.includes('?') ? '&' : '?'
        const es = new EventSource(`${this.url}${sep}pointId=${encodeURIComponent(pointId)}`)
        es.onmessage = (event) => {
            const data = JSON.parse(event.data)
            const point: DataPoint = {
                id: data.id || pointId,
                value: data.value ?? data.data,
                timestamp: data.timestamp || Date.now(),
                quality: data.quality || 'good',
            }
            for (const cb of this.callbacks.get(pointId) || []) cb(point)
        }
        es.onerror = () => {
            // EventSource 会自动重连，这里仅记录
            console.warn('[SSE] 连接异常，浏览器将自动重连')
        }
        this.sources.set(pointId, es)
    }
}
```

要点：

- **每点独立 EventSource**：`sources: Map<pointId, EventSource>`；`unsubscribe` 调用 `es.close()` 并移除。
- **自动重连**：由浏览器内建，无需手写重连逻辑；`onerror` 仅记录日志。
- **URL 拼接**：自动判断 `?`/`&` 追加 `pointId` 并编码。
- `disconnect()` 关闭全部 EventSource 并清空回调。

## 四、数据格式与点ID约定

| 方向 | 内容 | 说明 |
| --- | --- | --- |
| 前端 → 接口 | `GET <url>?pointId=<pointId>`（`Accept: text/event-stream`） | 建立 SSE 流 |
| 接口 → 前端 | `data: {"id"?, "value", "timestamp"?, "quality"?}\n\n` | 标准 SSE 帧 |

可选控制帧：`retry: <ms>\n\n`（重连间隔）、`event: <name>\n`（命名事件，当前实现仅监听默认 `message`）。

## 五、内置模拟服务

文件：`mock/server.ts` 的 `startSseServer()`，监听 `http://localhost:8082`，路径 `/sse`：

```ts
const clients = new Map<string, Set<http.ServerResponse>>()
const server = http.createServer((req, res) => {
    const url = new URL(req.url || '/', `http://localhost:${MOCK_PORTS.sse}`)
    res.setHeader('Access-Control-Allow-Origin', '*')
    if (url.pathname === '/sse') {
        const pointId = url.searchParams.get('pointId') || 'default'
        res.writeHead(200, {
            'Content-Type': 'text/event-stream',
            'Cache-Control': 'no-cache',
            Connection: 'keep-alive',
        })
        res.write('retry: 3000\n\n')
        if (!clients.has(pointId)) clients.set(pointId, new Set())
        clients.get(pointId)!.add(res)
        req.on('close', () => clients.get(pointId)?.delete(res))
        return
    }
    res.writeHead(404); res.end()
})
setInterval(() => {
    const t = Date.now()
    for (const [pointId, resps] of clients) {
        const data = JSON.stringify({ id: pointId, value: sseValue(pointId, t), timestamp: t, quality: 'good' })
        for (const res of resps) res.write(`data: ${data}\n\n`)
    }
}, 1000)
```

数据生成算法（`mock/generators.ts`）——锯齿斜升，10 秒周期 0→100 后归零：

```ts
export function sseValue(pointId: string, t: number): number {
  const period = 10000
  const offset = (hashPhase(pointId) / (2 * Math.PI)) * period
  return round1((((t + offset) % period) / period) * 100)
}
```

## 六、路由与节点绑定机制

`useDataService.ts`：

```ts

    service = new SseService(sourceUrl)

```

绑定回调把 `point.value`（经可选 `transform`）写入 `node.data.value`，与其余数据源一致。

## 七、扩展指南

- **支持命名事件**：当前仅 `es.onmessage`（默认 `message` 事件）。若服务端用 `event: alarm` 等命名事件，需 `es.addEventListener('alarm', handler)`。
- **携带鉴权**：原生 `EventSource` 不支持自定义请求头；如需 token，通常通过查询参数 `?token=xxx` 传递（在 URL 拼接处追加）。
- **共享连接**：若希望多点复用一条 SSE 连接，可改为单连接 + 服务端在 JSON 中带 `id` 区分，前端按 `id` 分发到各回调（重构 `sources` 为单实例）。
- **修改模拟数据**：编辑 `sseValue()`。

## 八、调试与验证

1. `npm run dev`，控制台出现 `[mock] SSE 服务已启动: http://localhost:8082/sse?pointId=xxx`。
2. 浏览器控制台动态验证：

```js
const { SseService } = await import('http://localhost:5173/src/services/SseService.ts')
const svc = new SseService('http://localhost:8082/sse')
svc.subscribe('progress.task.01', p => console.log(p.value))
// 每秒输出锯齿斜升数值；验证完 svc.disconnect()
```

3. `curl -N "http://localhost:8082/sse?pointId=x"` 可看到持续的 `data: {...}` 流（`-N` 关闭缓冲）。
